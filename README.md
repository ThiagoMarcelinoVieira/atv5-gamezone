# 🎮 GameZone Retro

Este repositório contém a página web **GameZone Retro**, uma loja fictícia de jogos clássicos. O projeto foi desenvolvido como atividade prática da disciplina de Desenvolvimento de Sistemas.

## 📁 Estrutura do Projeto
Com base no repositório `atv5-lima` (conforme a referência image_47bcaa.png), o projeto é composto por:
* `05a_desafio.html`: O arquivo HTML principal com a estrutura da página.
* `retro.jpg`: A imagem utilizada no cabeçalho da loja.

## 🛠️ Tecnologias e Conceitos Utilizados
O projeto foi construído utilizando **HTML5** puro, aplicando as seguintes marcações estruturais:
* **Textos e Hierarquia:** Uso de `<h1>`, `<h2>` e `<p>` para títulos e descrições.
* **Formatação:** Aplicação de `<strong>` e `<em>` para dar ênfase visual às palavras.
* **Links (Navegação):** Uso da tag `<a>` tanto para ancoragem interna (Ver Preços) quanto para navegação externa (Instagram).
* **Mídia:** Inserção de imagens através da tag `<img>`.
* **Listas:** Uso de listas não ordenadas (`<ul>` e `<li>`) para catalogar os consoles disponíveis.
* **Tabelas:** Construção de uma tabela de preços (`<table>`, `<tr>`, `<th>`, `<td>`) para organizar jogos, plataformas e valores.

## 🚀 Como Visualizar
1. Faça o download ou clone o repositório.
2. Certifique-se de que os arquivos `05a_desafio.html` e `retro.jpg` estejam na mesma pasta.
3. Abra o arquivo `05a_desafio.html` em qualquer navegador web (Chrome, Edge, Firefox, etc.).
